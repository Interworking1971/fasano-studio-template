# Example client instantiation — ASD Corpus Wellness (Fasano)

A worked example of re-skinning this template for a real client: a gym in
Fasano, Puglia running eight disciplines.

- `site.ts` — the content layer re-pointed to that client. Drop it in at
  `content/site.ts` to see the template wearing a different brand.
- `shotlist.md` — the photography brief generated for it, mapping every image
  slot to a specific shot.

Nothing here is imported by the template. It exists to show what a client
instantiation looks like, and to keep `main` neutral and reusable.
